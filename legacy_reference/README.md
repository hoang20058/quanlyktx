# Legacy reference

Thu muc nay chua cac file da tach khoi luong chay chinh sau khi du an chuyen sang **Modern Procedural PHP / Page Controller**.

Noi dung trong day chi de doi chieu:

- `api/`: endpoint JSON cu.
- `models/`: Repository cu.
- `docs/`, `system_analysis/`, `BAO_CAO_HE_THONG_QUANLYKTX.md`: tai lieu mo ta kien truc cu.
- `tools/`, `src/`, `core/Api.php`, `config/database.php`: tien ich va lop ho tro cu.
- `contracts_thamkhao.php`: file tham khao hop dong, khong thuoc luong chay chinh.

Khi chay hoac thuyet trinh he thong hien tai, hay uu tien cac file trong `public/`, `views/partials/`, `core/`, `config/app.php`, `assets/` va `database/`.
